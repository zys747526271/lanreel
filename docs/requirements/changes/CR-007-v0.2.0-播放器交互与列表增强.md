# CR-007 v0.2.0 播放器交互与列表增强

## 背景

v0.1.0 交付后，用户在实际使用中提出 8 项反馈：设置/后台往返丢失播放位置、网页端缺全屏按钮、倍速模式退出方式反直觉、控件布局、桌面端鼠标/键盘操作缺失、手机网页 UI 不可见、观看历史与收藏夹排在一起、缩略图无效果。本变更覆盖这 8 项。

## 决策与实现

1. **会话恢复用 sessionStorage 而非 KeepAlive**：随机流列表本身是随机生成的，KeepAlive 会保留整棵组件树但无法覆盖刷新/整页跳转。改为在 `pagehide` 与组件卸载时保存 `{sessionKey, items, activeIndex, positions}`，回到播放器时先恢复，再决定是否追加加载；`sessionKey` 区分游客与各登录用户，避免串号。
2. **全屏作用于条目容器而非 document**：对整条 slide 调 `requestFullscreen()`，控制条仍可见；媒体用 `object-contain` 保持比例，避免拉伸。iOS 回退到 `webkitEnterFullscreen()`。
3. **倍速手势与竖滑切换的冲突判定**：按下 500ms 内纵向位移超过 14px 判定为切换手势、取消长按；超过 500ms 进入倍速模式，之后纵向每 34px 切一档。松开保持档位，半透明提示按钮单击退出并恢复 1×。
4. **桌面鼠标拖动切视频**：同一套 pointer 手势同时服务触摸与鼠标；手势层 `touch-action: none`，上滑/下滑超过 40px 触发 advance/retreat，短按仍为暂停/继续。
5. **键盘语义**：空格从「下一个」改为暂停/继续；上下键切视频；左右键首次按下立即 seek 3s，按住每 120ms 追加 3/5/8s，keyup/blur 停止。
6. **移动端可见性**：顶栏和底部控制条改为 `bg-black/55` 高对比常显、40px 触控区、`env(safe-area-inset-*)` 安全区；信息条与右侧操作栏上移避开控制条。
7. **观看历史独立**：新增 `/history` 页，收藏夹/历史顶部互切；设置页只保留入口，不再混排历史列表；播放器返回按来源回 `/favorites` 或 `/history`。
8. **封面回退**：服务端 `thumb_url` 恒为接口地址，先 HEAD 探测是否真有缩略图；缺失时悬停创建挂载到 DOM 的静音 video，按 5 个采样点（约 10 秒）seek 并 canvas 抽帧，JPEG data URL 写入 IndexedDB `thumbs` store；网格优先展示缓存帧，其次服务端缩略图，最后占位图。
