# CR-002 首次部署改为网页引导创建管理员

- **提出时间**：2026-11-24
- **类型**：需求变更（用户明确要求，覆盖 F-24 原实现方式）
- **状态**：已实现并实测
- **影响范围**：初始化流程、认证接口、前端路由、部署文档、配置项语义

## 1. 背景

原始需求 F-24 规定「管理员账号由启动配置初始化（如 `ADMIN_INIT_PASSWORD`），不通过注册产生」，
目的是避免「谁先注册谁当管理员」。但这带来两个实际使用问题：

1. 首次部署必须先在命令行准备环境变量，再手动输入用户名密码，对非技术用户不友好；
2. 忘记设置 `ADMIN_INIT_PASSWORD` 时服务直接启动失败，而随意设置的初始密码又容易长期不更换。

用户要求对齐常见开源项目的首次使用体验：**部署完成后打开网页即进入管理员创建页面，创建完成即可使用；
后续每次启动不再出现该页面，直接进主页**。

## 2. 变更内容

### 2.1 首次初始化走网页引导

- 新增 `GET /api/v1/setup/status`：返回 `setup_required`。
- 新增 `POST /api/v1/setup/admin`：仅在未初始化时可用；创建 `role=admin` 账号并直接签发令牌（自动登录）。
- 前端新增 `/setup` 页面：用户名、密码、确认密码，创建成功后 `replace('/')` 进入主页。
- 路由守卫在最前面检查 `setup_required`：为真时任意入口都重定向到 `/setup`；已初始化后访问 `/setup` 会被导向主页/登录页。

### 2.2 初始化状态的判定与持久化

- 新增设置项 `setup_completed`（写入业务库 `system_settings`），创建管理员成功后置为 `1`。
- 判定顺序：`setup_completed=1` → 不需要初始化；否则若库中已有启用管理员 → 视为已初始化（兼容旧版本升级的实例）；
  否则需要初始化。
- `POST /setup/admin` 用互斥锁串行化并二次校验状态，已初始化后返回 `409 setup_completed`。

### 2.3 保留无浏览器部署路径

- `ADMIN_INIT_PASSWORD`（或配置 `auth.init_password`）不再是必填项：
  - 提供：启动时按 `auth.username`（默认 `admin`）创建管理员并写入 `setup_completed=1`，跳过网页引导；
  - 未提供：不创建任何账号，等待网页引导创建，避免默认弱口令。
- `--reset-admin-password` 兼容网页创建的用户名：当 `auth.username` 不存在时，重置**最早创建的启用管理员**的密码，
  保证「忘记密码」仍有一条命令行恢复路径。

## 3. 兼容性

- 已有实例升级：启动时 `InitializeAdmin` 检测到管理员存在即标记 `setup_completed=1`，不会弹出初始化页面；
  原有账号、密码、收藏、策略均不受影响。
- 新增接口与字段，未修改既有请求/响应结构，`/api/v1/` 版本号不变。
- 安全边界：初始化页面只在「无管理员且未标记完成」时可用，避免「谁先打开谁当管理员」；
  最后一个管理员不可被删除（`AdminService.DeleteUser` 既有约束），因此不会因误删重新打开初始化入口。

## 4. 验证记录

| 场景 | 预期 | 实测 |
|------|------|------|
| 全新实例打开 `/` | 重定向 `/setup` | ✅ `/setup` |
| 未初始化时直接访问 `/admin/dashboard` | 仍进入 `/setup` | ✅ `/setup` |
| 提交创建表单 | 直接进入主页，显示「后台」入口 | ✅ 路径 `/`，`hasAdminLink=true` |
| 初始化后再访问 `/setup` | 回到主页/登录页 | ✅ `/`（已登录）、`/login`（无令牌） |
| 重启服务后（新浏览器） | 直接到登录页，不出现初始化页 | ✅ `/login` |
| 重复初始化 | `409 setup_completed` | ✅ 409 |
| 全新实例 + `ADMIN_INIT_PASSWORD` | 跳过引导，配置账号可登录 | ✅ `setup_required=false`，登录 200 |
| 网页创建的管理员 + `--reset-admin-password` | 新密码可登录、旧密码 401 | ✅ 200 / 401 |

## 5. 未纳入本次变更

| 想法 | 处理 |
|------|------|
| 初始化页绑定一次性口令（远程部署防抢注） | 当前定位局域网部署，且初始化只在无管理员时开放；如需公网暴露再评估 |
| 初始化时一并设置媒体目录 / 扫描任务 | 属配置项，保持「配置文件负责路径、网页负责账号」的边界 |
