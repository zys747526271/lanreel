# CR-005 缩略图、文件监听与登录限流（B-01 / B-04 / B-05）

- **提出时间**：2026-11-24
- **类型**：需求补齐（backlog 三项）
- **状态**：已实现并实测
- **影响范围**：媒体扫描、缩略图接口、后台媒体页、登录接口、配置项

## 1. 背景

`backlog/v0.1.0.md` 中 B-01（缩略图）、B-04（文件监听）、B-05（登录限流）在 v0.1.0 未完成：

- 视频缩略图一直 404，收藏夹与后台列表只能用渐变占位；
- 目录变化依赖定时全量扫描（默认 60 秒），「放进去就能看」体验差；
- 登录接口无失败限制，多人环境下存在爆破风险。

## 2. 变更内容

### 2.1 缩略图（B-01）

- 新增 `internal/thumb`：单 worker 队列，扫描完成后入队，不阻塞扫描与请求。
  - **图片**：标准库解码 + 双线性缩放（无第三方依赖），输出 JPEG；
  - **视频**：调用 ffmpeg 抽帧（默认第 1 秒、宽 480），Windows 下以隐藏窗口 + 最低优先级运行；
  - 输出到 `{data_dir}/thumbs/{video_key}.jpg`，先写临时文件再原子重命名；源文件未更新则跳过。
- ffmpeg 探测顺序：`media.ffmpeg_path` → `PATH` → 程序所在目录；缺失时只记一次日志并跳过视频，其余功能不受影响。
- `/media/:key/thumb` 优先返回生成的缩略图（图片、视频统一），否则图片回原图、视频 404（前端占位）。
- 后台「媒体目录」页新增缩略图卡片：视频/图片覆盖率、ffmpeg 状态、失败数，并提供「重新生成」。

### 2.2 文件系统监听（B-04）

- 新增 `media.Watcher`（`fsnotify`）：递归监听媒体根与子目录，新增目录自动纳入；
  事件去抖 2 秒后触发一次扫描；每 15 秒对齐一次根目录（后台改目录后自动纳入）。
- 监听目录数超过 `watch_max_dirs`（默认 4096）时停止新增，退回定时扫描；
- 定时扫描保留为兜底（`scan_interval_seconds`）。

### 2.3 登录失败限流（B-05）

- `auth.LoginLimiter`：IP 与用户名双维度滑动窗口，默认 5 次失败 / 5 分钟窗口 / 锁定 5 分钟，成功登录清零；
- 触发锁定返回 `429 too_many_attempts` + `Retry-After`，并写 `auth` 分类告警日志；
- 内存实现，启动清零；每 10 分钟清理过期桶；
- 配置：`auth.login_max_attempts` / `login_window_minutes` / `login_lock_minutes`。

## 3. 验证记录

| 场景 | 结果 |
|------|------|
| 图片缩略图 | 6 张图片全部生成 JPEG（宽 480），`/thumb` 返回 `200 image/jpeg` |
| 视频缩略图（真实 ffmpeg） | 安装 ffmpeg 9.1 后重建：`flower.mp4` 生成宽 480 的 JPEG（12750 字节），`ffmpeg -f null` 解码通过，人工确认为视频首帧画面；`/thumb` 返回 `200 image/jpeg` |
| 重建缩略图 | `POST /admin/thumbs/rebuild` 返回 `queued=7`，统计 `generated` 增长、`failed=0` |
| 新增文件触发扫描 | 新建 `新建目录/inside.png` 后约 3 秒媒体数 6→7，日志出现「检测到媒体目录变化」 |
| 登录限流 | 连续 5 次错误密码后第 6 次返回 `429`，`Retry-After: 299`；正确密码也被拒（锁定期） |
| 限流单测 | `TestLoginLimiterLocksAfterThreshold` / `WindowExpiry` / `Reset` 通过 |

## 4. 配置项

```yaml
media:
  thumbnail_enabled: true
  thumbnail_width: 480
  thumbnail_seek_seconds: 1
  ffmpeg_path: ""          # 留空自动探测
  watch_enabled: true
  watch_debounce_seconds: 2
  watch_max_dirs: 4096
auth:
  login_max_attempts: 5
  login_window_minutes: 5
  login_lock_minutes: 5
```
