# CR-006 播放器交互、收藏夹网格与设置页改版

- **提出时间**：2026-11-24
- **类型**：体验改进（用户逐条反馈）
- **状态**：已实现并实测
- **影响范围**：播放组件、浏览页、收藏页、设置页、本地偏好与观看历史

## 1. 背景与变更

### 1.1 默认有声播放

- 原来进入浏览页默认静音，用户需手动点喇叭。
- 现在默认**尝试有声自动播放**；被浏览器自动播放策略拒绝时自动降级为静音，
  弹提示「已静音播放，点击画面开启声音」，任意点击恢复声音，且这一次点击不再触发暂停。
- 「默认静音」可在设置页按设备覆盖。

### 1.2 进度条只在按下时跳转（修复）

- 原实现 `pointermove` 无条件先 `seek` 再判断按键，导致鼠标悬停/触摸划过就改变播放位置。
- 现在：`pointerdown` 才开始跳转并捕获指针，拖动实时更新，松手保持；悬停只显示把手，不改变进度；
  拖动期间显示时间气泡，并暂停 `timeupdate` 覆盖显示避免抖动。

### 1.3 收藏夹改为缩略图网格

- 新增 `/favorites`：3–6 列自适应缩略图网格（视频带时长与播放角标，不可播放条目模糊 + 原因）。
- 点击格子才进入 `/favorites/play?key=…` 全屏播放：上下滑动切换、可取消收藏、左上返回网格并恢复滚动位置。
- 浏览页顶部原「随机/收藏」分段切换改为「收藏夹」入口，避免两套收藏 UI。

### 1.4 设置页改版

- **普通用户不再显示本地运行日志**（含导出/清空）；日志能力收归管理员，全站日志在后台「运行日志」。
- 新增「播放设置」（设备级，localStorage）：默认静音、默认倍速（0.5/1/1.25/1.5/2/3）、
  从收藏/历史播放时自动全屏、全屏时自动横屏（移动端）。
- 新增「观看历史」：本地 IndexedDB `history` store，最多 100 条，按最近观看排序，可单条删除/清空，
  点击回到播放；记录规则为停留超过 1.5 秒，避免快速滑动污染。
- 新增「关于 LanReel」：项目简介、能力清单、版本、GitHub 仓库与许可证。

## 2. 数据与兼容

- IndexedDB 版本 1 → 2，新增 `history` store；升级时自动建表，不影响收藏与日志。
- 播放偏好保存在 `localStorage`（键 `lanreel.prefs`），不写服务端，多设备互不影响。
- 收藏接口与数据结构未变，`/favorites/play`、`/play?src=history` 为新增前端路由。

## 3. 验证记录

| 场景 | 结果 |
|------|------|
| 默认有声 | 进入浏览页 `video.muted=false`，自动播放（`paused=false`） |
| 自动播放被拒 | 拦截 `play()` 模拟策略拒绝：降级 `muted=true` + 提示出现；点击后 `muted=false` 且不暂停 |
| 进度条悬停 | 暂停后悬停、无按键滑动：`currentTime` 0.37 → 0.37（不跳转） |
| 进度条拖动 | 按下拖到 50%：`currentTime` 0.37 → 2.76（总长 5.05） |
| 收藏网格 | 4 条收藏渲染 4 张缩略图（全部加载成功），不可播放条目显示原因徽标 |
| 收藏播放 | 点击进入 `/favorites/play?key=…`，上滑切到第 2 条，返回落到 `/favorites` |
| 默认倍速 | 设置 2× 后进入浏览页 `video.playbackRate=2` |
| 普通用户设置页 | 无「本地运行日志」；有「播放设置 / 观看历史 / 关于 LanReel」 |
| 观看历史 | 浏览后设置页出现历史缩略图；可清空、可单条删除 |
| 控制台 | 端到端脚本 `PROBLEMS=[]` |
