# CR-003 媒体目录可在后台配置并热重扫

- **提出时间**：2026-11-24
- **类型**：需求变更（用户反馈「管理员页面看不到设置视频文件夹的地方」）
- **状态**：已实现并实测
- **影响范围**：媒体扫描、后台设置、管理接口、部署文档

## 1. 背景

F-06 只要求「支持配置多个媒体文件夹」，原实现把目录写死在配置文件 `media.roots` 里，
后台只有「文件夹策略」（对已扫描出来的目录做可见性控制），没有任何「添加/更换媒体目录」的入口。
实际使用时，用户部署完想换一个文件夹必须改 `config.yaml` 再重启，与「后台可管理」的预期不符。

## 2. 变更内容

### 2.1 后台新增「媒体目录」页

- 列出当前生效目录，标注来源（`配置文件` / `后台设置`）。
- 支持输入路径或通过**目录浏览器**逐级进入选择（Windows 列盘符，其他系统列 `/`；隐藏目录不列出）。
- 保存后立即热更新扫描根目录并在后台重扫，页面轮询扫描结果（总条目/视频/图片、耗时、错误）。
- 提供「恢复配置文件设置」，清除后台覆盖后回落到 `media.roots`。
- 页面明确提示：更换目录会重算文件标识，旧收藏可能失效；仅新增目录时旧收藏不受影响。

### 2.2 数据与生效顺序

- 新增设置项 `media_roots`（业务库 `system_settings`，JSON 数组）。
- 生效顺序：`media_roots`（后台保存）优先；未设置或已被清除时使用 `config.media.roots`。
- 启动时读取该设置并 `scanner.SetRoots(...)`，重启后保持后台配置。
- 保存时校验：路径必须存在且是目录、去重、最多 16 个、至少 1 个；失败返回 `400 validation_failed`。

### 2.3 新增接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/settings/media` | 目录列表、来源、扫描间隔、最近扫描统计 |
| PUT | `/admin/settings/media` | 保存目录（校验 + 热重扫 + 审计） |
| DELETE | `/admin/settings/media` | 清除后台设置，回落配置文件 |
| GET | `/admin/fs/dirs?path=` | 目录浏览器（仅管理员，只列子目录，最多 500 项） |

## 3. 兼容性

- 未使用后台设置时行为与旧版本完全一致（配置文件即生效目录）。
- 媒体 `video_key` 由 `sourceID + rootIndex + 相对路径` 计算：**新增**目录不影响已有条目的 key；
  **更换/删除**目录会改变根索引，相关条目的 key 变化，旧收藏会显示为不可播放（页面已提示）。
- 已知限制（沿用 backlog B-07）：文件夹策略以源内相对路径为键，多根下同名目录共享同一条策略。

## 4. 验证记录

| 场景 | 预期 | 实测 |
|------|------|------|
| 初始读取 | 来源 `config`，1 个目录，3 条媒体 | ✅ `source=config`、`media_total=3` |
| 后台添加第 2 个目录 | 保存后 `source=database`，重扫后 5 条 | ✅ `roots=2`、`media_total=5`（视频 1 / 图片 4） |
| 目录浏览器 | 从盘符逐级进入并选中目录 | ✅ `C:\ → Users → zhou9 → … → lanreel-media2`，选中后进入待保存列表 |
| 无效路径 | 400 并说明原因 | ✅ `validation_failed: C:/nope/nope（目录不存在或不可访问）` |
| 重启服务 | 仍使用后台设置的 2 个目录 | ✅ `source=database`、`roots=2`、重扫 `total=5` |
| 移除目录 | 回落到 1 个目录，3 条媒体 | ✅ `media_total=3` |
| 恢复配置文件设置 | 清除覆盖并回落到 `media.roots` | ✅ 列表回到 1 项 |
| 前台播放 | 新目录中的图片可被随机流返回 | ✅ `GET /media/random` 返回 5 条 |
| 控制台 | 无报错 | ✅ `PROBLEMS=[]` |

## 5. 未纳入本次变更

| 想法 | 处理 |
|------|------|
| 目录内单文件排除/包含规则 | 现由「文件策略」按文件禁用；批量忽略规则等有真实需求再做 |
| 扫描进度百分比 | 扫描为遍历目录，只能给出「进行中」；结果统计已足够判断 |
| 多根目录策略隔离 | 需把策略键改为 `rootIndex + 相对路径` 并迁移旧数据，见 B-07 |
