# LanReel v0.3.3 发布说明

> 版本定位：v0.3.2 之后的修复版本。直接替换 exe 即可，数据库与账号数据无需迁移。

## 主要变更

### 1. 观看热度「媒体」表默认隐藏已移除文件

- 新增「隐藏已移除文件」开关，**默认开启**：只统计扫描库中仍存在的文件，分页总数同步为可见条目数。
- 关闭开关后仍可查看全部历史统计行（含 v0.3.2 引入的「已移除 · 文件名」标记），用于核对历史播放与收藏数据。
- 过滤在服务端排序和分页之前完成，避免前端只隐藏当前页导致页码与总数不一致。
- 新增查询参数 `hide_missing`（默认 `true`），老客户端不传该参数时也按隐藏处理。

## 验证情况

- 前端 `npm run typecheck` / `npm run build` 通过；后端 `go vet ./...` / `go test ./...` 全部通过。
- 新增后端回归测试：开启隐藏后分页总数与条目数均为 0，关闭时保持原有 3 条；原有路径恢复、空名兜底与排序稳定性测试继续通过。
- 重建 `dist/lanreel.exe`，`--version` 输出 `lanreel 0.3.3`；发布包包含 exe、配置示例与使用说明。
- 交互层验证止于构建与单测；浏览器端到端复测需启动服务后在后台「观看热度与统计」页人工确认。

## 升级说明

- 直接替换 `lanreel.exe` 即可，无需数据库迁移；浏览器本地偏好自动兼容旧版本。
- 若看不到某些历史统计，关闭媒体表上的「隐藏已移除文件」开关即可。
