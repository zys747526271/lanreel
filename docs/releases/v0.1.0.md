# LanReel v0.1.0

局域网私有媒体浏览器：一个二进制、一个配置文件，把电脑或 NAS 上的视频/图片变成可上下滑动的信息流。不需要云服务、不需要数据库服务、不联网。

首个可用版本，覆盖原始需求 v3.1 的 41/43 项功能与 27/29 项非功能要求，详细对照见 [completed/v0.1.0.md](../requirements/completed/v0.1.0.md)。

## 快速开始

1. 解压，把 `config.example.yaml` 里的 `media.roots` 改成你的媒体目录，另存为 `config.yaml`
2. 运行 `lanreel.exe --config config.yaml`
3. 浏览器打开 `http://127.0.0.1:8080`，按引导创建管理员（用户名密码自定，只在首次部署时出现）
4. 局域网其他设备访问 `http://<本机IP>:8080`，未登录即以游客身份浏览

## 这个版本能做什么

**浏览**
- 全屏竖向滑动（触摸 / 滚轮 / 键盘 ↑↓ / 空格），视频自动播放、离开即暂停，图片按配置停留后自动翻页
- 默认有声；浏览器拦截自动播放时自动降级静音并提示，点一下画面恢复声音且不会误触暂停
- 进度条按下才跳转、按住可拖动，鼠标悬停或手指划过不再误跳
- 收藏夹为缩略图网格，点开进全屏连播，可继续上下滑，返回落回原来的网格位置
- 观看历史（本机保存最近 100 条），可单条删除或清空，点击续播

**账号与可见性**
- 首次部署在网页里创建管理员，之后每次启动直接进主页
- 游客（未登录）可直接浏览管理员开放的内容；登录后可见范围更大，并能收藏
- 每个文件夹/文件策略分别控制「普通用户可见」与「游客可见」，时间窗口共用
- 策略按媒体根隔离：多个根目录下的同名子目录互不影响
- 登录失败按 IP + 用户名双维度限流，超限返回 `429` 并记录告警

**媒体管理**
- 后台「媒体目录」可增删扫描目录（内置目录浏览器），保存后立即热重扫，无需改配置重启
- 文件系统监听：目录内容变化约 2 秒后自动扫描，定时扫描作为兜底
- 服务端缩略图：图片由服务端缩放，视频用 ffmpeg 抽帧；后台可查看覆盖率并一键重建
- 多库分离：业务库与日志库各自独立文件，日志脱敏、按级别与保留天数清理，支持按分类/级别/关键词检索

## 配置要点

| 项 | 说明 | 默认 |
|----|------|------|
| `server.port` | 监听端口 | `8080` |
| `media.roots` | 媒体目录，可多个；后台保存后会覆盖此项 | `./media` |
| `media.thumbnail_enabled` | 是否生成缩略图 | `true` |
| `media.ffmpeg_path` | ffmpeg 路径，留空则在 PATH 与程序目录查找 | 空 |
| `media.watch_enabled` | 是否启用文件监听 | `true` |
| `auth.login_max_attempts` | 窗口内允许的登录失败次数 | `5` |
| `auth.login_lock_minutes` | 超限后的锁定分钟数 | `5` |
| `app.timezone` | 判定时间窗口所用时区 | `Asia/Shanghai` |

完整说明见 [README](../../README.md) 与 [deploy](../../deploy/README.md)。

## 已知限制

- 无 Tauri 桌面端与手机/电视客户端，浏览器访问为主（需求 F-32 / F-33 未实现）
- 长按快进、长按上下滑动调倍速尚未实现：与「上下滑切换」共用纵向手势，需先定冲突判定（backlog B-10）
- 视频缩略图依赖 ffmpeg；未安装时视频在收藏夹/列表中显示占位图，播放不受影响
- 文件标识基于「根目录序号 + 相对路径」：重命名媒体文件或更换媒体目录会导致旧收藏失效
- 日志关键词检索使用 `LIKE %kw%`，日志量很大（>50 万条）时变慢
- Linux 交叉编译未做实机验证（Docker 构建可用），Windows 为实测平台

## 验证情况

- `go vet ./...`、`go test ./...`、`vue-tsc --noEmit` 全部通过（含策略判定、登录限流单测）
- 端到端（Edge 实机渲染）：游客浏览、登录收藏、收藏网格与全屏连播、进度条拖拽、默认倍速生效、后台三大页、控制台零报错
- 首次部署流程：空库打开任意地址进创建页，创建后直进主页；重启后不再出现，重复初始化返回 `409`
- 旧数据库升级：不弹初始化页，既有账号与收藏保持可用
