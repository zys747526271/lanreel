# LanReel v0.3.2 发布说明

> 版本定位：v0.3.1 之后的修复与收口版本。直接替换 exe 即可，数据库与账号数据无需迁移。

## 主要变更

### 1. 观看热度「媒体」表不再出现空白名称

- 根因：`media_stats` 会保留已被扫描移除文件的统计行，这些行没有当前媒体条目、`rel_path` 为空；按「媒体 / 热度 / 播放 / 完播 / 时长 / 收藏」正序排列时，0 值行排到第一页，前端取空路径的文件名后显示为空白。
- 服务端新增路径快照回退链：当前扫描库 → 观看历史中同一 key 最近一次的相对路径 → 收藏记录中的路径 → `video_key`。每一条统计行都会返回非空 `display_name`。
- 已移除文件标记 `missing=true`，表格显示「已移除 · 文件名」并置灰，悬停提示「文件已移除，仅保留历史统计」；点击这类行不再跳转到文件策略页。
- 名称排序改用补全后的显示名，并忽略「已移除」前缀；路径解析同时兼容 `/` 与 `\`，中文文件名不会被截断。

### 2. 用户统计表空用户名兜底

- 账号被删除后观看排行中的用户名可能为空，现在显示「已注销用户 #用户 ID」，避免同样出现空白单元格。

### 3. 收口此前已实现但未打 tag 的改动

- 策略实时同步：版本变更通过 SSE + 轮询双通道推送，当前视频被禁用自动跳过，重新开放后此前未加载的媒体会并入随机流并恢复继续加载；收藏 / 历史播放页可滑动跳过不可播放项。
- 管理端：固定侧栏、真实系统诊断页、危险操作归入系统设置、文件策略增加热度指标、热度三表全量排序后分页并支持点击行跳转定位。
- 上述交互的细节见 [v0.3.1 发布说明](./v0.3.1.md)；v0.3.2 是这些改动进入正式 tag 的版本。

## 验证情况

- 前端 `npm run typecheck` / `npm run build` 通过；后端 `go vet ./...` / `go test ./...` 全部通过。
- 新增 4 组后端回归测试：路径文件名解析（含 Windows 分隔符与尾部分隔符）、历史路径优先于收藏快照、三种正序下显示名非空且带「已移除」标记、六种字段倒序稳定。
- 用当前真实业务库（166 条媒体统计，其中 35 条为文件已移除的孤立行）只读模拟：按「媒体 / 播放 / 热度」正序的第一页均无空白名称。
- 重建 `dist/lanreel.exe`，`--version` 输出 `lanreel 0.3.2`；发布包包含 exe、配置示例与使用说明。
- 交互层验证止于构建与单测；浏览器端到端复测需启动服务后在后台「观看热度与统计」页人工确认。

## 升级说明

- 直接替换 `lanreel.exe` 即可，无需数据库迁移；浏览器本地偏好自动兼容旧版本。
- 已移除文件的历史统计不会被删除，仍会显示在热度表中并带「已移除」标记；如需彻底清除，可在数据库中删除对应 `media_stats` 行。
