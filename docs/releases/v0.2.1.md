# LanReel v0.2.1

发布日期：2026-11-24

## 本版定位

v0.2.0 的**纯修复版本**：修正观看历史的权限遮挡过时问题，以及长按倍速的交互回归。API 保持向后兼容（仅新增一个只读批量状态接口），数据库结构、媒体 key 与前端 IndexedDB 均无破坏性变更，可直接在 v0.2.0 上覆盖升级。

## 修复内容

| 反馈 | 修复后的行为 |
|------|--------------|
| 观看历史没有像收藏夹那样对无权限条目做遮挡；即使做了，历史里存的是加入时的旧快照，后来被禁用的条目仍显示正常封面 | 新增 `POST /api/v1/media/status`（viewer 权限，单次最多 200 key）批量返回条目的实时 `playable/reason`，文件不存在的条目返回 `file_missing`。历史页加载后以该接口刷新快照；无权限封面使用 `scale-125 + blur-2xl + brightness-[0.45] + saturate-50` 高斯模糊与暗化，叠加半透明黑层、居中锁图标和**具体原因**（如「该内容已被管理员禁用」），隐藏播放按钮与时长角标，模糊到无法辨认原画面 |
| 上下滑动调速必须一直按住才有效，松手后倍速不保持 | 改为 Kazumi 式手势：松手即保持当前倍速并收起中央面板，无需右滑确认；再次长按从当前倍速继续调节 |
| 长按倍速松手后中央面板不消失 | `pointerup` / `pointercancel` 时立即收起中央面板，只在底部保留半透明的「当前倍速 · 恢复原速」提示 |
| 长按倍速应默认 1.5×，而不是沿用当前倍速 | 首次长按 500ms 即进入 **1.5×**，上下滑动在 0.5× / 1× / 1.25× / 1.5× / 2× / 3× 间选档；单击底部提示恢复到设置页默认倍速，单击画面仍是暂停/播放 |

## 主要改动文件

- 服务端：`server/internal/api/media_handler.go`（新增 `handleMediaStatus`）、`server/internal/api/router.go`（注册 `POST /media/status`）
- 前端：`web/src/api/media.ts`（`fetchMediaStatus`）、`web/src/lib/history.ts`（记录 reason）、`web/src/views/HistoryView.vue`（加载时刷新实时权限）
- 前端：`web/src/components/media/MediaThumb.vue`（强模糊）、`web/src/components/media/MediaGrid.vue`（居中遮挡与原因提示）
- 前端：`web/src/components/reel/ReelSlide.vue`（Kazumi 式倍速：默认 1.5×、松手保持并收起面板）
- 版本：`Makefile`、`web/package.json`、`server/cmd/lanreel/main.go` 统一为 0.2.1

## 验证

- `npm run typecheck`、`npm run build`、`go vet ./...`、`go test ./...` 全部通过
- `POST /api/v1/media/status` 实测：不存在的 key 返回 `{ playable: false, reason: "file_missing" }`
- Edge headless 端到端：
  - 历史页禁用条目居中显示「该内容已被管理员禁用」；有封面的条目 `blur-2xl / scale-125 / brightness-[0.45]` 全部命中，原画面不可辨认，无播放图标
  - 长按进入后倍速面板显示 1.5× 且 `playbackRate=1.5`；上滑一档变 2×；松手后面板消失但保持 2×；点击底部提示回到 1×
  - 单击画面仍为暂停/播放，未被倍速手势误吞

## 升级说明

- 直接替换二进制即可；v0.1.0 / v0.2.0 的 `data/` 与浏览器 IndexedDB 都无需迁移。
- 若从旧版本升级，历史中此前被禁用但仍显示正常封面的条目，会在打开观看历史页时自动刷新为遮挡状态。
- 仓库内不含任何凭据；需要 GitHub 操作的票据请继续通过环境变量或仓库外文件提供。
