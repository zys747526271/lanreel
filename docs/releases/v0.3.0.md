# LanReel v0.3.0 发布说明

> 版本定位：大功能版本（数据模型与账号体系升级）。从 v0.2.1 升级直接替换 exe 即可，数据库会自动执行 `0003_watch_stats` 与 `0004_accurate_stats` 迁移，浏览器数据无需清理。

## 第一批修复

- **播放器页面保活**：借鉴同类短视频项目的条件缓存方案，浏览页 / 收藏播放页改用 `<KeepAlive>` 保活。切到设置、收藏夹、历史、后台时只暂停并上报进度，返回时复用同一个 `<video>` 元素和播放位置，不再用 sessionStorage 快照重建页面。手机端全屏改为 CSS 铺满，避免原生全屏在横竖屏旋转时触发 WebView 重载（黑屏、串音、需要多次返回）。只有浏览器导航类型为 `reload` 时才清除会话并重新随机。
- **长按倍速 UI**：长按进入倍速立即隐藏其他 UI，松手立即恢复完整控件；倍速为 1× 时不再显示「恢复原速」按钮；手势取消 / 切换条目时也会正确恢复。
- **文件夹热度显示**：后台「观看热度与统计 → 文件夹」同时显示媒体源名称与实际文件夹路径，根目录项不再全部只显示「根目录」。

## 第二批修复

- **收藏管理**：收藏网格支持长按弹出「取消收藏」（管理员屏蔽的条目也能取消）、批量勾选取消收藏、一键清理「文件已丢失」的收藏；不会误删被管理员屏蔽但文件仍存在的条目。
- **观看历史判定**：只有播放器真正触发 `play` 才写历史，预加载与缩略图抽帧不再产生历史；拖动进度条不再计入观看时长与完播。
- **真实完播**：完播按累计真实观看时长 ≥ 视频时长判定，服务端校验并修正旧数据；完播计数只在首次达标时 +1。
- **热度公式**：改为 `log(完播)×12 + log(观看时长/60)×6 + log(收藏)×3 + log(播放)`，完播权重最高。
- **今日与历史统计**：管理端新增「今日全站观看 / 今日观看时长」，原卡片改为「历史全站观看 / 历史观看时长」。
- **恢复初始化**：管理端概览新增红色危险按钮，输入「确认初始化」后清空账号、收藏、历史、策略、统计与日志，回到首次部署状态（不删除媒体文件）。
- **文件夹名显示**：播放页视频标题下显示实际文件夹名；根目录文件显示媒体源名称。
- **沉浸模式**：播放器新增沉浸模式按钮，隐藏所有 UI，仅保留退出按钮；开启 3 秒后退出按钮转为半透明，悬停/触摸恢复。
- **移动端全屏**：手机端优先调用原生全屏并尝试锁定横屏；不支持时回退 CSS 铺满，横竖屏切换后自动重新对齐当前视频。

## 第三批修复

- **观看历史实时性**：播放器 `play` 事件立即上报并写入历史，不再被 5 秒节流挡住；每次真实开始播放都会增加播放次数，「从头开始」不会重复计数。切换视频时立即补报上一条。
- **历史播放路由缓存**：KeepAlive 缓存的播放页现在监听 `route.query.key/src` 变化，重新拉取历史/收藏列表并聚焦到新视频，避免从历史点开不同视频却仍播放旧条目。
- **沉浸按钮文案**：控制栏沉浸按钮改为「沉浸」两个字。
- **分层手势**：参考 ZFPlayer / TigerVideoPlayer 的方向锁定思路，全屏 / 沉浸模式横滑拖动快进；全屏竖滑调音量，不再切换视频；普通模式保留竖滑切视频。全屏与沉浸叠加时全屏手势优先，功能不重叠。
- **首页下拉刷新**：浏览页第一条视频下拉重新随机（仅非全屏状态；全屏竖滑已被音量占用），其它条目上滑仍为下一个视频、下拉仍是上一个视频。

## 第四批修复

- **首页下拉刷新**：在播放器手势与滚动容器两层同时判定第一条视频的下拉，控件区域下拉也能重新随机；刷新时排除当前整批并提示「已刷新随机列表」，媒体较多时不会刷回同一条。
- **收藏批量管理**：批量管理模式内新增「一键清除失效视频」按钮，可直接删除文件已丢失的收藏（不误删被管理员屏蔽但仍存在的条目）；网格卡片建立独立层叠上下文、顶部栏提升层级，上滑列表时勾选框不再浮到其它 UI 上层。
- **沉浸模式进度反馈**：沉浸模式下横滑快进与长按倍速会临时弹出进度条和时间，操作结束约 0.9 秒自动收起；倍速恢复按钮与退出沉浸按钮一致，开启 3 秒后转为半透明，触摸/hover 恢复清晰。
- **播放结束黑屏全面排查**：视频结束后统一进入结束态，覆盖封面与「点击重播」层（沉浸/全屏下同样可见）；自动下一个在最后一条时改为重播，不再停在黑帧；切后台返回、canplay 回派等路径不再把结束态误判为新播放；补充 iOS 私有全屏退出同步。

## 本次新增（11 项需求）

### 一、账号隔离与播放进度（需求 1 / 2 / 7）
- **观看历史改为服务端存储、按用户隔离**：原浏览器 IndexedDB 全局共用，现每个账号独立；管理员看不到普通用户的历史。
- **每用户播放进度云端同步**：播放时按约 5 秒节流上报位置/观看时长/播放次数，离开或切换时补报。
  - 从收藏夹 / 观看历史打开：自动续播，顶部出现「从头开始」按钮（点击清零服务端进度并从 0 播放）。
  - 随机流刷到看过的视频：默认从头播放；设置页「随机刷到看过的视频从头播放」开关可改为续播。
  - 已看完（≥95%）的视频再次打开自动从头。
  - 收藏 / 历史网格显示观看进度条（部分观看显示彩色进度条，看完显示「已看完」角标）。
- **收藏数按当前视频统计**：播放器收藏按钮显示的是该条媒体的收藏次数，不再是全站/本人总数。

### 二、播放体验（需求 3 / 4 / 8）
- **播放结束行为**：设置页可选「暂停 / 循环播放 / 自动下一个」，默认暂停。
- **快进时间提示**：长按 ←/→ 快进或倍速调速时，画面下方显示醒目的「当前时间 / 总时长」。
- **极简快进 UI**：快进 / 倍速期间自动隐藏顶部栏、右侧操作栏、信息条与所有按钮，只保留底部进度条与时间，停止操作 1.6 秒后恢复。

### 三、统计与推荐（需求 5）
- 设置页新增「我的观看统计」：观看视频数、完整播完数、总观看时长（按实际看过部分累计）。
- 管理端仪表盘新增「观看热度与统计」：全站汇总卡片 + 媒体 / 文件夹 / 用户三档热度排行榜，展示播放次数、完播数、观看时长、收藏量。
- 热度评分（第二批修复后）：`log(完播)×12 + log(观看时长/60)×6 + log(收藏)×3 + log(播放)`，完播权重最高（供推荐算法参考）。
- **推荐接口预留**：`GET /api/v1/admin/recommend?limit=&exclude=`，当前返回热度候选，未来可接协同过滤/向量召回。

### 四、策略与管理（需求 9 / 10）
- **播放时段按用户 / 游客独立**：文件夹策略与文件级策略中，普通用户与游客各有自己的「始终 / 时间窗口 / 禁用」设置，互不影响。
- **文件夹递归导入**：添加媒体目录时可单独选择是否递归导入子目录；开启后有媒体文件的子文件夹独立出现在文件夹策略树中。
- **文件夹树管理**：同一媒体根的根目录行可折叠 / 展开子文件夹，根与子目录均可单独配置策略；根目录编辑时提供「同步到所有子文件夹」按钮。
- 文件夹策略表格显示每个目录的播放次数 / 观看时长 / 收藏量。

### 五、其它（需求 6 / 11）
- **UI 精修**：登录 / 注册页改为品牌化玻璃卡片与光晕背景、图标输入框；设置页统计卡片化；管理端仪表盘 / 文件夹 / 媒体目录页重排信息层级。
- **移除服务端旧缩略图生成**：删除 ffmpeg 抽帧生成器、后台缩略图统计/重建接口与设置区块、配置中的 thumbnail/ffmpeg 项。封面统一由浏览器在收藏夹 / 历史页抽帧并缓存，不再占用服务端磁盘。

## API 变更

新增（均需登录；管理端接口需管理员）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/history?limit=` | 当前用户观看历史（服务端隔离，带实时权限与进度） |
| DELETE | `/api/v1/history`、`/api/v1/history/:key` | 清空 / 删除单条历史 |
| GET | `/api/v1/progress` | 当前用户进度快照 |
| POST | `/api/v1/progress` | 上报进度（含 `first` 首播标记） |
| POST | `/api/v1/progress/restart` | 从头开始（清零进度） |
| GET | `/api/v1/me/watch-summary` | 当前用户观看统计 |
| GET | `/api/v1/admin/watch/heat/media` | 媒体热度排行 |
| GET | `/api/v1/admin/watch/heat/folders` | 文件夹热度排行 |
| GET | `/api/v1/admin/watch/heat/users` | 用户观看排行 |
| GET | `/api/v1/admin/recommend` | 推荐候选（预留接口） |

移除：`GET /api/v1/admin/thumbs/stats`、`POST /api/v1/admin/thumbs/rebuild`。

数据库新增 `0003_watch_stats` 迁移：watch_history / media_stats / folder_stats / media_root_options 表，以及 folder_policies / file_overrides 的游客时段列。

## 升级说明

- 直接替换 `lanreel.exe` 即可；首次启动自动执行数据库迁移，无需手动干预。
- 旧浏览器里的本地观看历史不再使用，历史统一走服务端（按账号），首次升级后各账号历史从新的观看记录开始积累。
- 配置文件中的 `thumbnail_*` / `ffmpeg_path` 已废弃，可保留（会被忽略）或删除。
