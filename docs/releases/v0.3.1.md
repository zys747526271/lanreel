# LanReel v0.3.1 发布说明

> 版本定位：v0.3.0 之后的交互修复版本。直接替换 exe 即可，数据库与账号数据无需迁移。

## 主要变更

### 1. 手势操作可配置（设置 → 手势与播放操作）

- 设置页新增二级页面 `/settings/gestures`，按「普通播放 / 沉浸模式 / 全屏模式」三类场景分别配置；沉浸与全屏叠加时以全屏配置为准。
- 每类场景可单独设置：单击画面、双击画面、上下滑动、左右滑动、长按倍速开关。
- 默认值：
  - 普通播放：单击暂停/播放、双击点赞收藏、上下滑动切换视频、左右滑动无操作、长按倍速。
  - 沉浸模式 / 全屏：单击暂停/播放、双击点赞收藏、上下滑动调音量、左右滑动拖动快进、长按倍速。
- 播放结束行为（暂停 / 循环 / 自动下一个）归入同一二级页面的「通用播放行为」分组，主设置页保留入口链接。
- 旧配置自动补齐缺失字段并过滤非法取值，升级后不会出现未定义手势。

### 2. 双击点赞与单击分流

- 单击延迟约 240ms 等待双击窗口；窗口内第二次点击执行点赞/收藏，不会先暂停。
- 双击配置为「无操作」时单击立即响应，不引入延迟。
- 点赞状态在浏览页、收藏播放页、历史播放页保持一致；取消收藏会同步更新收藏数，从收藏列表播放时同步移出当前列表。

### 3. 全屏首次点击修复

- 点击时先按真实 DOM 状态同步全屏标记，修复 Esc 退出或外部清理后缓存状态不一致导致首次点击无效的问题。
- 移除请求全屏前会消耗用户手势的 `await exitFullscreen()`；补充 iOS 私有全屏进入/退出事件同步。
- 从收藏/历史播放页返回时同时退出播放器自身全屏并解锁横屏。

### 4. 操作逻辑梳理

- 用时间戳替代残留式点击抑制标记，避免一次手势吞掉后续正常点击。
- KeepAlive 切走的页面不再响应后台自动播放；同一视频的并发 `play()` 请求合并。
- 沉浸模式下倍速面板与手势提示不再被全局隐藏规则吞掉；沉浸模式的下拉不再误触发随机刷新。
- 进度上报去除近邻重复事件；播放结束对齐时间点；播放器引用按媒体 key 索引，列表重排后不再拿到旧实例。
- 收藏夹「一键清除失效视频」只在批量管理面板内显示，顶部不再常驻。

### 5. 可播放策略实时同步

- 服务端策略判定器维护全局版本号；文件夹/文件策略变更、恢复初始化、媒体目录变更都会使版本递增并通过 SSE 推送给所有在线客户端。
- 新增 `GET /api/v1/events/policy`（事件流）与 `GET /api/v1/events/policy/version`（轮询兜底）。事件只带版本号，不透传策略内容或用户信息。
- 客户端收到版本变化后调用 `POST /api/v1/media/status` 批量重查当前与后续视频：
  - 当前视频被禁用或超出时段时暂停、退出全屏并跳到下一个可播放项；
  - 随机流中被禁用的条目即时隐藏，重新开放后自动回到列表；
  - 管理员「开放」了此前从未加载过的文件时，随机流会主动拉取当前可播放媒体并入列表（以全部已知 key 去重），并恢复继续加载能力，无需等当前视频播完或手动往下滑；
  - 收藏夹/观看历史的模糊封面与原因提示同步刷新，无需重新进入页面；
  - KeepAlive 页面切回时补一次重查，避免后台期间漏掉变更。
- 事件流断线由浏览器自动重连，事件流内下发 `retry: 2000` 缩短重连等待；连接建立时先发送当前版本。
- 实测发现单二进制 HTTP/1.1 服务下，整批视频带 `src` 会占满浏览器同源连接队列，导致 SSE 要等视频播完才连上。本次收敛为只给当前项和相邻预载项设置 `src`，并保留前台 1.5 秒 / 后台 10 秒的轻量版本轮询双通道；回到前台立即补查。
- 事件流半开超过 90 秒会切换到轮询，并在 10 秒后尝试重建 SSE；轮询请求为短连接，不依赖长连接可用性。
- 播放页每 30 秒、网格页每 60 秒重查一次，覆盖时间窗口到期、文件丢失等不产生后台写事件的情况。
- 不可播放条目仍保留在收藏/历史播放列表中，但手势层继续可用：点击或上下滑动直接跳过；再次打开策略后按原进度续播。

### 6. 管理端信息架构与诊断增强

- 左侧导航改为固定侧栏，内容区独立滚动；管理员信息卡片沉底，退出登录改为醒目的红色按钮。
- 右上角「诊断」改为独立的系统诊断页（`GET /api/v1/admin/diagnostics`），真实检测：数据库 `PRAGMA quick_check`、媒体目录可达性与丢失文件（抽样）、最近扫描任务、播放策略版本、近 24 小时日志错误/告警、内嵌前端资源、数据目录可写性；每项给出状态、详情与修复建议。数据目录检测会创建并立即删除一个临时文件。
- 概览顶部卡片压缩为一行，日志分类分布并入「媒体扫描」卡片，不再单独占整行；运行配置保留紧凑布局并新增诊断入口。
- 「危险操作 · 恢复初始化」从概览移到「系统设置」页。
- 文件策略列表增加「热度 / 播放 / 收藏」列，与文件夹策略页指标一致。
- 观看热度与统计三张表改为服务端全量排序后再分页（每页 10 条）：点击「热度 / 播放 / 完播 / 时长 / 收藏 / 名称」表头切换排序，再点切换正序/倒序；点击媒体、文件夹、用户行分别跳转到文件策略、文件夹策略、用户管理并高亮定位。

## 验证情况

- 前端 `typecheck` / `build`、后端 `go vet` / `go test ./...` 全部通过。
- 新增服务端单测：策略版本递增、订阅/退订与 SSE 首帧 + 变更帧广播、版本查询接口。
- 端到端实测（最终 v0.3.1 二进制）：三场景配置写入后普通单击切换下一条；双击出现收藏提示且视频未暂停；沉浸模式关闭左右滑动后时间不随横滑跳变、倍速面板可见；全屏首次点击即进入；顶部无清理按钮、批量管理内出现「一键清除失效视频」。原有下拉刷新、沉浸进度 HUD、播放结束重播与批量勾选层级回归通过。
- 策略实时同步验证入口：禁用当前视频后客户端自动跳到下一条；禁用后续视频后随机流即时隐藏；重新开放策略后条目恢复可播；开放此前从未加载的文件后随机流即时加入新视频且往下滑可继续加载；收藏/历史网格模糊状态同步刷新；不可播放的收藏/历史条目仍可点击或上下滑动跳过。该交互需在后台策略页与浏览页双开时人工复核。

## 升级说明

- 直接替换 `lanreel.exe` 即可，浏览器本地偏好自动兼容旧版本。
- 若手势行为与预期不同，进入「设置 → 手势与播放操作 → 恢复该场景默认」即可复位。
