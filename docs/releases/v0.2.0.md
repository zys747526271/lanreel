# LanReel v0.2.0

发布日期：2026-11-24

## 本版定位

v0.1.0 之后的体验增强版本：补齐播放器手势与桌面控制、全屏按钮、会话进度恢复、观看历史独立页，以及无 ffmpeg 环境下的悬停抽帧封面。后端 API 与数据结构未做破坏性变更，数据库/媒体 key 可直接沿用 v0.1.0。

## 新增与改进

| 需求 | 实现 |
|------|------|
| 设置/后台往返保持视频与进度 | 新增 `lib/session.ts`：离开播放器时把随机流列表、当前索引与每条 `currentTime` 写入 sessionStorage；返回后恢复同一批视频、同一条与进度；设置页/后台的「返回前台」直达进入前的播放器路由 |
| 网页端全屏按钮 | 播放器底部控制条新增全屏按钮，对当前条目容器请求全屏；视频/图片使用 `object-contain` 按原始比例显示（黑边填充），不拉伸；移动端与桌面端均可用 |
| 倍速模式退出方式 | 长按画面 500ms 进入倍速模式，上下拖动在 0.5×/1×/1.25×/1.5×/2×/3× 间选档并保持；单击半透明倍速提示按钮即退出并恢复 1×，无需再次长按 |
| 控件布局 | 静音、播放/暂停、进度与时间、全屏统一到底部控制条；右侧「上一个/下一个」按钮加大并加标签；顶部收藏/历史/设置/后台触控区加大，移动端常显；安全区适配 |
| 桌面端控制 | 鼠标上下拖动切换视频；长按 ←/→ 持续快退/快进（随按住时间加速）；空格改为暂停/继续；↑↓/PageUp/PageDown 切换视频 |
| 手机网页 UI | 顶部导航与底部控制条改为高对比常显样式，收藏、历史、设置均可直接点按；安全区与 100dvh 适配 |
| 观看历史 | 从设置页移出，新增独立 `/history` 网格页；收藏夹与历史页顶部可一键互切；播放器返回按钮回到对应列表 |
| 缩略图 | 服务端缩略图缺失（如未安装 ffmpeg）时，悬停卡片在约 10 秒内快速跳播采样 5 帧并抽帧，缓存到 IndexedDB 作为封面；历史与收藏共用 |

## 验证

- `npm run typecheck`、`npm run build` 通过；`go test ./...` 全部通过
- Edge headless 端到端：390×844 与 1280×800 下 UI 可见、无横向溢出
- 实测：设置页往返后仍是同一视频且进度保留；空格暂停/继续；长按右方向键 1.1 秒进度由 3.3s 增至 5.0s；长按上拖倍速升至 2×，点击提示恢复 1×；鼠标上拖滚动位置 0→800 切换视频；全屏时视频 `object-fit: contain` 按原始比例显示

## 0.2.0 修订（同日交互修复）

首轮实测后又修正了 4 个问题，已合入同一版本的二进制：

| 问题 | 修正 |
|------|------|
| 从设置/收藏/历史返回后，恢复的视频与首条视频会同时播放 | 新增 `lib/playerRegistry.ts` 页面级播放器注册表：每次 `play()` 前暂停其它播放器，`play()` 完成后再复核 `active` 状态；离开播放器页面统一暂停全部视频 |
| F5 刷新仍停留在原来的随机流与进度 | 会话只在 SPA 路由离开时保存；全局 `pagehide` / `beforeunload` 清除全部播放器会话，刷新后重新随机加载 |
| 倍速提示浮在画面中央遮挡视频 | 去掉中央大浮层，改为底部控制条内的半透明倍速徽标（显示当前倍速，单击退出并恢复 1×） |
| 封面必须悬停才生成、悬停时只有进度条在走 | 无服务端缩略图时，卡片进入视口即自动抽首帧并缓存（跳过纯黑片头）；悬停改为隐藏视频静音连续预览，canvas 每约 120ms 换帧，进度条平滑推进约 10s，离开后回落到已缓存封面 |

修订版验证：返回后同时播放的视频数恒为 1；刷新后 `sessionStorage` 无播放器会话且回到第一条；倍速徽标位于底部（1280×800 下 y≈760）且点击后消失；无缩略图时视频卡片 5 秒内自动生成 `data:image/jpeg` 封面，悬停 1.5s 与 3.7s 的帧与进度条均发生变化；无请求拦截时控制台零报错。

## 0.2.0 交互再修订（同日）

根据实测反馈又调整了两处，参考 `mpvRx-CN` / `webVideo` 的长按倍率面板，以及 `peekbar` / `youtube-hover-preview` 的抽帧预览：

| 反馈 | 最终行为 |
|------|----------|
| 倍速选择提示应在视频中央半透明显示，确认后才消失；右侧按钮太挤 | 长按 500ms 后中央显示半透明倍率面板（上/下滑动调速），**松手不关闭**；向右滑动 >44px 确认后中央面板消失，底部才出现「倍速 · 恢复 1×」提示，单击恢复原速。设置入口从顶栏/右侧操作栏移到左侧偏中（1280×800 下 x≈12、y≈336），右侧仅保留切换与收藏 |
| 缩略图悬停只快进前一小段，进度条走完内容没跳完 | 改为 12 段「分段跳播 + 段内快进」：每段 seek 到对应时间点后以最高 12× 播放约 0.83s，canvas 每约 110ms 抽帧，约 10s 覆盖全片；进度条到 100% 时预览到达最后一帧并停留 350ms 后收起 |

再修订验证：长按后面板在中央、底部提示不出现；纵滑后倍率 1×→1.5×；右滑后面板消失、底部出现「1.5× 恢复 1×」；点击后 `playbackRate` 回到 1。悬停预览进度条 15.8%→54.8%→95.0%，隐藏视频 `currentTime` 1.12s→2.94s→4.88s（总时长 5.05s），最终 seek 到末帧。

> 本版发布后的三项交互修复（历史实时权限遮挡、Kazumi 式倍速）已单独作为 **v0.2.1** 发布，见 [v0.2.1 发布说明](./v0.2.1.md)。

## 升级说明

- 直接替换二进制即可；v0.1.0 的 `data/` 无需迁移。
- 浏览器 IndexedDB 由 v2 升到 v3，首次打开会新增 `thumbs` store，原收藏与历史不受影响。
- 需要 GitHub 操作的旧票据请继续通过环境变量/配置文件提供，仓库内不含任何凭据。
